# API существующего приложения

Ответ: `{"data": ...}`; ошибка: `{"error": "описание"}` с соответствующим
HTTP-статусом. JSON UTF-8. Заголовок `X-Demo-User: 1` выбирает Анну,
`2` — Бориса, `3` — Веру. По умолчанию 1. Это открытый демо-переключатель,
не доказательство личности; локальный API не предназначен для публикации в сеть.

| Метод и путь | Текущее поведение |
|---|---|
| `GET /api/health` | Проверка запуска сервиса |
| `GET /api/context` | Демо-пользователи, выбранный пользователь, время UTC и дата создания демо |
| `GET /api/projects` | Только проекты текущего пользователя, участники и количество задач |
| `GET /api/attention` | Обзор внимания в активных проектах, которыми руководит текущий пользователь |
| `GET /api/projects/{id}/tasks` | Все задачи доступного проекта |
| `POST /api/projects/{id}/tasks` | Создать задачу в активном проекте |
| `GET /api/tasks/{id}` | Доступная задача с комментариями и авторами |
| `PATCH /api/tasks/{id}` | Изменить поля с проверкой версии |
| `POST /api/tasks/{id}/comments` | Сохранить комментарий от текущего пользователя; ответ 201 с созданным комментарием и автором |

Поля задачи для создания и изменения: `title`, `description`, `status`,
`assignee_id`, `due_at`. При создании `title` обязателен. Неизвестные поля
отклоняются. Исполнитель — участник проекта или `null`. Даты — строго
`YYYY-MM-DDTHH:mm:ssZ` либо `null`; текущий UI редактирует их с точностью до минуты.
Для PATCH обязательно целое поле `version`, полученное при чтении.
Успешное изменение увеличивает версию; устаревшая версия возвращает 409.
Метод добавления комментария принимает только `{"body":"текст"}`. Автор берётся
из текущего демо-пользователя, передать другого автора нельзя. Создание комментария
не изменяет версию полей задачи и не мешает сохранить открытый черновик её полей.
Версия и ответ 409 относятся к конкурирующим PATCH самой задачи. Чтение полного
обсуждения с авторами доступно через карточку задачи.

Максимумы строк в байтах UTF-8: название 200, описание 10000, комментарий 5000.
Максимум тела изменения — 32 KiB. Ошибка валидации — 422, JSON — 400,
неизвестный пользователь — 401, отсутствующий или недоступный объект — 404,
запись в архив — 409. Поиск и фильтр статуса в текущем UI выполняются локально.

## Обзор внимания

`GET /api/attention` возвращает `data.items`, `data.counts`, `data.server_now`.
В `items` попадают незавершённые задачи всех исполнителей, включая неназначенные:
пользователь одновременно владеет проектом и состоит в нём, проект не архивный.
Чужие проекты, архив и завершённые задачи исключаются на сервере.

Элемент содержит поля задачи, `project_name`, `signals` (массив `{code,label}`),
`score`, `evidence` (последний комментарий с текстовым признаком или `null`),
`description_signal`, `latest_comment`, `comment_count`.
Коды причин: `blocked`, `request`, `overdue`, `unassigned`, `soon`.
`counts` считает каждую причину отдельно: у одной задачи их может быть несколько.

Оценка равна максимальному весу причины: 100, 90, 80, 60, 30 соответственно.
Сортировка — оценка по убыванию, срок по возрастанию (без срока в конце), ID.
Просрочка означает срок строго раньше серверного времени; ближайший срок — от
текущего момента до 48 часов включительно. `request` — эвристика фраз в описании
и обсуждении, а не установленный факт нерешённой эскалации. `evidence` может быть
старше последнего комментария; полную переписку следует читать в карточке.
Пагинации нет. Фильтры проекта, причины и поиска применяются в интерфейсе.
